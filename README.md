# Offload

App per la barra dei menu di macOS che importa le schede SD (Sony, DJI, DJI Mic e altre fotocamere)
nei lavori, con verifica SHA-256 e backup su un secondo disco.

Qui ci sono solo le versioni pronte da installare: il codice non è pubblico.

## Installare
1. Scarica `Offload-<versione>.pkg` dall'ultima [Release](../../releases/latest).
2. Doppio clic. Se macOS lo blocca: **Impostazioni di Sistema → Privacy e sicurezza → Apri comunque**.
3. Apri Offload da Applicazioni: l'icona compare nella barra dei menu.

Requisiti: Mac Apple Silicon, macOS 14 o successivo.

## Aggiornamenti
Dalla versione 1.5.9 Offload controlla da sola se c'è una versione nuova e la propone nel menu ⚙︎.
